1. ¿Qué es el software pirata?

El software pirata es cualquier programa de computadora que ha sido modificado ilegalmente para que puedas usarlo gratis, sin pagar licencia.

menu_book ¿Qué es el Malware?
Es la palabra técnica para cualquier programa malicioso (viene de "malicious software"). Incluye virus, troyanos, spyware y ransomware.

2. ¿Qué hay dentro de un "crack"?

keyboard Registrador de Teclas

Un programa que graba todo lo que escribes: contraseñas, números bancarios, mensajes privados.

door_open Puerta Trasera (Backdoor)

Crea un acceso oculto a tu dispositivo. El hacker puede encender tu cámara, ver tus archivos, o descargar tus fotos.

warning La mayoría de estos programas te piden que desactives el antivirus para "funcionar bien". Ese es el momento en que entran en tu sistema. NUNCA desactives el antivirus.
